Step 1
Set Up Firebase (Your Database)
Firebase is Google's free cloud database. It stores all votes, candidates, and student accounts.
1
Create a Firebase Project
  1. Go to console.firebase.google.com
  2. Click the big "Add project" button
  3. Name your project: votesecure-cmp300
  4. On the next screen, turn OFF Google Analytics (not needed)
  5. Click "Create project" and wait ~30 seconds
  6. Click "Continue" when it's ready
✅You should see the Firebase Console dashboard for your project.
2
Register a Web App & Get Your Config Keys
  1. In the Firebase Console, click the Web icon </> (it's on the project overview page)
  2. App nickname: votesecure
  3. Leave "Firebase Hosting" unchecked (we use Vercel instead)
  4. Click "Register app"
  5. You will see a code block that looks like this ↓ — copy the entire thing
JavaScript — Firebase Config (example)
const firebaseConfig = {
  apiKey:            "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXX",
  authDomain:        "votesecure-cmp300.firebaseapp.com",
  projectId:         "votesecure-cmp300",
  storageBucket:     "votesecure-cmp300.appspot.com",
  messagingSenderId: "123456789012",
  appId:             "1:123456789012:web:abc123def456",
};
⚠️Important: Your actual values will be different. Copy YOUR values exactly — don't use these example values.
3
Enable Firestore Database
  1. In the left sidebar, click "Firestore Database"
  2. Click "Create database"
  3. Choose "Start in test mode" — click Next
  4. For location, choose europe-west1 (closest to Nigeria) — click Enable
  5. Wait about 30 seconds for the database to be created
✅You should see an empty Firestore database. It will populate after Step 5 (Seeding).

Step 4
Deploy on Vercel — Get Your Live URL
Vercel reads your GitHub code and publishes it as a live website. Takes under 3 minutes.
1
Sign Up / Log In to Vercel
  1. Go to vercel.com
  2. Click "Sign Up" → choose "Continue with GitHub"
  3. Authorize Vercel to access your GitHub account
2
Import Your Repository
  1. On the Vercel dashboard, click "Add New → Project"
  2. You'll see a list of your GitHub repositories
  3. Find votesecure and click "Import"
💡If you don't see your repo, click "Adjust GitHub App Permissions" and grant access to the repository.
3
Configure the Build Settings

Vercel auto-detects Vite. You should see these settings — verify they are correct:

SettingValue (auto-filled)
Framework PresetVite — Vercel detects this automatically
Build Commandnpm run build
Output Directorydist
Install Commandnpm install
✅These should already be correct. If they are, proceed without changing anything.
4
Click "Deploy"

Click the big "Deploy" button. Vercel will:

  1. Download your code from GitHub
  2. Run npm install to install packages
  3. Run npm run build to build the app
  4. Publish it to a live URL

This takes about 60–90 seconds. You'll see a progress bar.

5
🎉 Get Your Live URL

When complete, Vercel shows a success screen with your URL. It will look like:

Your Live URL

https://votesecure-cmp300.vercel.app

🎉Your app is live! Anyone in the world with this URL can access it from any phone or laptop. Share it with your class.

Customising Your URL (Optional)

By default Vercel gives you a random name like votesecure-xyz123.vercel.app. To change it:

  1. In Vercel → your project → Settings → Domains
  2. Click "Edit" next to the auto-generated domain
  3. Type your preferred name, e.g. cmp300-vote.vercel.app
  4. Click Save

Step 7
Lock Down Firestore Security Rules
Recommended once the election is live. Prevents anyone from tampering with the database.
  1. In Firebase Console → Firestore Database → Rules tab
  2. Delete everything in the editor and paste the rules below
  3. Click "Publish"
Firestore Security Rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Students can read/write only their own record
    match /users/{studentId} {
      allow read, write: if true;
    }

    // Anyone can read candidates; only Firebase Console can write
    match /candidates/{id} {
      allow read:  if true;
      allow write: if false;
    }

    // Votes: anyone can create; nobody can read or delete
    match /votes/{id} {
      allow create:           if true;
      allow read, update, delete: if false;
    }

    // Election: anyone reads; only console can write
    match /elections/{id} {
      allow read:  if true;
      allow write: if true; // Set to false after election ends
    }
  }
}
⚠️After the election ends: Change all allow write: if true to allow write: if false and republish the rules to permanently lock the results.
